# Інструкції для Claude

Мета: з теми зробити готове Shorts-відео (~50 с) російською з озвучкою, як у @RicksClips3000.

Пайплайн (кожне нове відео = новий make4.py за зразком make3.py: сцени, SCENES-текст, audio):
1. Вибери тему, напиши скрипт 6-7 сцен (текст у m.SCENES), коротко, з гумором, російською.
2. Озвучка: ElevenLabs (creative_generate_speech, eleven_v4, голос із creative_list_voices, ОДИН виклик, не повторювати). Сцени розділяй порожніми рядками.
3. Завантаж mp3 (потрібен доступ до elevenlabsusercontent.com), ffmpeg silencedetect -> тривалість кожної сцени -> durs.json.
4. `python3 make3.py preview`, подивись кадри (контактний аркуш), виправ, далі `render`.
5. Змікшуй голос поверх приглушеної (ducked) музики, віддай mp4.
6. Якість: окремі кадри перевіряти до повного рендеру; крок рендеру один.
Не обходь блокування мережі; якщо домен закритий — скажи користувачеві.
